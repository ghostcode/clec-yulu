# 投资语录 · CLEC 理财圣经

卡片式投资智慧语录网站，语录精选自《理财圣经 CLEC 版 v3.4.1》与《CLEC 宝典 V1.14.2》，采用墨金水墨风格呈现，支持一键分享。

## 技术栈

- **Vue 3**（`<script setup>` 组合式 API）—— 当前最主流的前端框架
- **Vite 5** —— 极速开发服务器与生产构建
- 原生 **Canvas** 生成语录分享图，无第三方 UI 库，零运行时负担

## 功能特性

- 📇 **卡片式语录**：每条投资金句以卡片呈现，按 10 大主题分类（觉醒、快乐、工具/管道、纪律、风险、杠杆、噪音、复利、趋势、传承）。
- 🔍 **搜索与筛选**：支持按关键词（语录 / 出处 / 主题）实时搜索，按分类标签快速过滤。
- 🎲 **随机一条**：一键随机抽取语录，灵感不重样。
- 🖼️ **详情弹窗**：点击卡片查看大字版语录与出处。
- 📤 **分享（三项）**：
  - **复制文字** —— 复制「语录 + 出处 + 话题标签」纯文本。
  - **复制图片** —— 将墨金语录卡片图复制到剪贴板（不支持的环境自动降级为下载）。
  - **保存图片** —— 直接下载 PNG 语录卡片（1080×1350，适配社交分享）。

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 生产构建（产物输出到 dist/）
npm run build

# 本地预览构建产物
npm run preview
```

> 要求 Node.js 18+。

## 目录结构

```
clec-quotes/
├── index.html          # 入口 HTML（含字体预连接、SEO meta）
├── vite.config.js      # Vite 配置（含 @vitejs/plugin-vue）
├── package.json
└── src/
    ├── main.js         # 应用入口
    ├── style.css       # 全局样式（CSS 变量：墨金配色、字体）
    ├── quotes.js       # 语录数据与分类定义（内容核心）
    ├── share.js        # 分享工具：Canvas 绘图、复制、下载
    └── App.vue         # 主组件：网格、筛选、搜索、弹窗与分享交互
```

## 内容说明

- 语录内容均为对原著的提炼与引用，仅供**学习与投资教育探讨**，**不构成任何投资建议**。
- 如需增删语录，编辑 `src/quotes.js` 即可；新增分类请在 `categories` 与 `ACCENTS` 配色表中同步补充。

## 浏览器兼容

- 复制图片依赖 `navigator.clipboard` + `ClipboardItem`（主流现代浏览器支持；不支持时自动降级为下载）。
- 字体使用 Google Fonts 的 Noto Serif SC / Noto Sans SC，离线环境下会回退到系统衬线/无衬线字体。
